# حسابینو | مدیریت مالی حرفه‌ای

نسخه PWA کاملاً آفلاین و بدون بک‌اند، مناسب GitHub Pages.

## امکانات اصلی
- دو حساب مستقل: شخصی و مغازه
- درآمد، هزینه، پس‌انداز و بودجه
- بدهکاران مشتریان
- وام و اقساط بانکی با فهرست بانک‌های ایران، تاریخچه پرداخت و هشدار سررسید
- ورود تاریخ‌ها به‌صورت شمسی با تقویم شمسی داخلی
- گزارش و نمودار
- PIN، مخفی‌کردن مبالغ و قفل برنامه
- Export/Import JSON و CSV
- PWA و اجرای آفلاین

## GitHub Pages
تمام فایل‌های این پوشه را در ریشه Repository قرار دهید و از Settings > Pages، شاخه main و پوشه root را انتخاب کنید.

## انتقال اطلاعات
از داخل برنامه Export JSON بگیرید و در گوشی جدید Import JSON کنید.
