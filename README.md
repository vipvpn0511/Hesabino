# مدیریت مالی حرفه‌ای — PWA
نسخه کاملاً مستقل برای GitHub Pages.
- بدون Backend، API یا سرور خارجی
- LocalStorage برای ذخیره اطلاعات
- PWA + Manifest + Service Worker
- دو حساب مستقل: شخصی و مغازه
- تراکنش، بدهکاران، پس‌انداز، بودجه، گزارش، JSON و CSV
- PIN Lock و مخفی‌کردن مبالغ
- سازگار با اجرای آفلاین پس از اولین بارگذاری

## نصب روی گوشی
1. فایل‌ها را در ریشه Repository قرار دهید.
2. GitHub Pages را روی branch و folder درست فعال کنید.
3. آدرس Pages را با Chrome باز کنید.
4. از منوی Chrome گزینه Install app / افزودن به صفحه اصلی را انتخاب کنید.
